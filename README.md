# Parser-telegram-proxies-list
Приложение для парсинга прокси мессенджера Telegram
Данная версия опирается на данные с .txt файлов https://github.com/kort0881/telegram-proxy-collector
За основу взяты proxy_ru.txt и proxy_eu.txt
Программа проверяет доступность и пинг до самих серверов. Однако, работоспособность всех серверов в качестве прокси для telegram не гарантируется, как и и блокировка.
